# Animated Elayo Family loader

Generated from `public/images/elayo/favicon.png` with the built-in image-generation tool. The original brand files are unchanged. `generated-parts.png` is the transparent source atlas; the four runtime WebP assets are in `public/images/elayo/loader/`. Each group was mechanically cropped, trimmed, resized, and compressed with Sharp. SVG positions the pieces; CSS animates them without JavaScript.

Prompt: Create a transparent four-quadrant atlas from the supplied Elayo Family icon: blue house roof/posts, three people, gold coin stacks with green/navy sprout, and blue cupped hands. Isolate each group, preserve logo shapes/colors, clean edges, no text/background/grid or extra elements.

The generated artwork is a loading illustration based on the logo, not a replacement for the original logo. The pieces assemble with staggered timing; reduced-motion uses a static assembled icon. No artificial loading delay.
